# Корневой сертификат УЦ

Сюда кладётся `ca.crt` — корневой сертификат нашего УЦ (тот же, что
`resources/ca.crt` в Dockerfile-ах). Плейбук `00` ставит его на каждую новую
машину ПЕРВЫМ: без него машина не доверяет https ProGet и не может скачать
GPG-ключ и пакет `ca-certificates-elara`.

Это публичный сертификат (не секрет) — его можно хранить в git.
Не путать с сертификатом сервиса (`.crt` + `.key` для https на nginx).
