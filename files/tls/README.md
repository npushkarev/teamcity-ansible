# Сертификат для https TeamCity (nginx)

Сюда кладутся два файла wildcard-сертификата `*.inc.elara.local`
(те же, что для остальных сервисов). Имена любые, важно только расширение:

- один сертификат: `.cer`, `.crt`, `.pem` или `.der` (PEM или DER; лучше с цепочкой:
  сертификат + промежуточный УЦ);
- один закрытый ключ: `.key` (без пароля).

Например:

```text
files/tls/inc.elara.local.cer
files/tls/inc.elara.local.key
```

В git эти файлы не попадают (`.gitignore`). Ключ можно зашифровать:
`ansible-vault encrypt files/tls/inc.elara.local.key` — плейбук всё равно
запускается с `--ask-vault-pass`.

Плейбук `50` проверяет, что ключ подходит к сертификату, сертификат
не просрочен и подходит к имени машины.

Не путать с корневым сертификатом УЦ (`files/ca/ca.crt`): он для доверия, а не для https.
